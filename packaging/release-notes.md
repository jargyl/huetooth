## Install

1. Download **Huetooth-Setup-…exe** below and run it.
2. Windows may say *"Windows protected your PC"* because the app is not code-signed. Click **More info → Run anyway**.
3. Huetooth starts and helps you add your lights. See the [README](https://github.com/jargyl/huetooth#connect-your-lights) for the 3 steps.

No admin rights and no Python needed. Prefer no installer? Download the **portable zip**, extract it and run `Huetooth.exe`.

Updating: just run the new setup. Your lights and settings are kept.
